# 戏墨宋 SC · Xi Mo Song SC

一款基于**思源宋体 CN** 改造的宋体，四个字重，取「紧中宫、饱字面、不削横」的调性。
**SIL Open Font License 1.1，免费商用。**

本仓库同时是这款字体的**落地页**（GitHub Pages）与网页字体分发点。

姊妹字体：[戏墨黑 SC](https://github.com/okko10086/ximohei)（基于思源黑体，六字重）。

## 设计说明

### 只收紧中宫，不加笔画对比

这是戏墨宋与姊妹款戏墨黑**最关键的差别**，也是本字体唯一的设计判断。

戏墨黑用了两个旋钮：中宫收紧加**方向性笔画对比**。黑体是等线，横竖一样粗，加对比是纯增益。

宋体不行——宋体本就靠横细竖粗立骨，横画已经被传统削到很薄，**没有余量再削第二次**。

实测（按 1000 upem 折算，取字形竖直中央列扫描墨迹连续段）：

| 字形 | 笔画本体 | 字面高度 | 占比 |
|---|---|---|---|
| 思源宋体「一」 | **33 单位** | 114 单位 | 29% |
| 思源黑体「一」 | **160 单位** | 160 单位 | 100% |

黑体横画削掉三成还剩 112；宋体横画削三成只剩 23 —— 在大字号下就是一根发丝，印刷上直接断线。

所以戏墨宋只做**中宫收紧**与**字面调整**，不接笔画对比。源码里保留了反面记录
（实验台的 `宋_加对比_错` 候选），可以清楚看到结构塌掉的样子。

### 两个旋钮

1. **中宫收紧 `k = 0.09`** —— 对局部缩放率建模，笔画只渐变变细、绝不增粗
2. **字面缩放 `sx = 1.055, sy = 1.045`** —— 略横向放宽，保持宋体方正偏扁的本性

实测效果：同一字号下「国」字的墨迹面积比由 0.846 增至 0.875，**放大 3.4%**，字面更饱满。

变形严格限定为 `x′=f(x)`、`y′=g(y)`，两者不交叉——这是 Type 2 charstring
编码正确性的硬约束（`hlineto` / `hvcurveto` 带隐式坐标，靠"相等"成立）。

### 水墨版为什么比黑体收敛

水墨位移需要足够大的笔画才承受得住。宋体横画只有 33 单位，
所以振幅**由横画而非竖画决定**，整体比黑体水墨小一档。

这是刻意的取舍：再往上加振幅，横画会被水渍啃断，字形散架。

### 几何安全由构造保证

沿法线偏移一旦超过局部半厚，轮廓就会自交或翻转绕向——字就坏了，而且**看起来可能
只是「有点怪」，不一定会立刻暴露**。故改为**逐字形检测 + 自适应降级**：
发现轮廓翻转或压没就降低强度重试（1.0 → 0.6 → 0.35 → 0）。

实测降级率：宋体水墨 0.00% / 0.07%。

## 网页字体

```css
@font-face {
  font-family: 'Xi Mo Song SC';
  src: url('fonts/ximosong-regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
body { font-family: 'Xi Mo Song SC', serif; }
```

- `fonts/ximosong-*.woff2` —— 落地页自用子集（783 字，约 254 KB / 字重）
- `fonts/full-ximosong-*.woff2` —— GB2312 完整子集（7,690 字符，约 2.5 MB），覆盖现代中文约 99.7%
- `fonts/ximosongink-*.woff2` —— 水墨标题体自用子集（约 268 KB / 字重）
